How to Join

GalaxySMP supports both editions of Minecraft. Java Edition runs on Windows, Mac and Linux. Bedrock Edition runs on phones, tablets, consoles and Windows (Microsoft Store).

Server address
  1. Launch Minecraft: Java Edition, version or newer.
  2. Select Multiplayer, then Add Server.
  3. Enter GalaxySMP as the server name and paste the server address.
  4. Select Done, then double-click GalaxySMP in your server list.
Server address
Port
  1. Launch Minecraft and select Play.
  2. Open the Servers tab and select Add Server at the bottom.
  3. Enter GalaxySMP as the server name, followed by the address and port.
  4. Select Save, then choose GalaxySMP and select Join Server.

Xbox, PlayStation and Nintendo Switch don't support adding custom servers directly. Our staff can help you connect. Ask in the #help channel.

Getting started

Choose a game mode

You will arrive in the hub. Select any NPC to travel to Survival, Minigames, Skyblock or Creative.

Join the community

Create an account on the Community page, then confirm it in game with /link and your code.

Having trouble connecting? Confirm the server is online on the Status page, check that the address is entered exactly as shown, and make sure Minecraft is up to date.
