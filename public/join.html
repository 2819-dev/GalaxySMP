How to join

Choose your version of Minecraft. Java runs on Windows, Mac and Linux computers. Bedrock runs on phones, tablets, consoles and the Microsoft Store version on Windows.

Server address
  1. Open Minecraft Java Edition. Version or newer works.
  2. Select Multiplayer, then Add Server.
  3. Enter GalaxySMP as the server name and paste the address above.
  4. Select Done, then double-click GalaxySMP in the list.
Server address
Port
  1. Open Minecraft and tap Play.
  2. Open the Servers tab and scroll to Add Server.
  3. Enter GalaxySMP as the name, then the address and port above.
  4. Tap Save, select GalaxySMP and tap Join Server.

Xbox, PlayStation and Switch don't let you add your own servers directly. Ask in the #help channel and staff will walk you through it.

After you join

Pick a world

You start in the hub. Walk up to an NPC and click it to travel to Survival, Minigames, Skyblock or Creative.

Link your account

Create a website account on the Community page, then type /link and your code in game.

Can't connect? Check the status page, make sure the address is typed exactly, and update Minecraft to the latest version.
