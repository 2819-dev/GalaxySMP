Recently handled

"Whole word only" blocks the word on its own, so adding "ass" still allows "class". "Anywhere" blocks it even when hidden inside other letters. The filter also catches spellings like sh1t, $hit and s h i t. Changes apply within a minute.

Ranks

Ranks show a colored prefix and icon in chat and above players' heads, and can let players use chosen commands without being operators. Changes reach the server within seconds. In game, operators can use /ranks.

Player money

New players get $1,000. Operators have infinite money (∞). Public list: Leaderboard.

Shop prices

Prices are in dollars. Leave Buy or Sell empty to turn it off for that item. Tap a category to edit it.

In-game Help menu

Players open it in game with /guide. It has three pages: Server Information, Rules and Commands. Put **two stars** around words to make them bold. The website's Rules page shows the same rules.
