Word filter

Checking…

"Whole word only" blocks the word on its own, so adding "cat" still allows "category". "Anywhere" blocks it even when hidden inside other letters. The filter also catches spellings like c@ts, caaats and c A t (if "cats" is on the list). Changes apply within a minute. A "Safe word" is never blocked, for real words that look like bad ones (for example a town name).

Test a message

Type anything to see if it would be allowed in chat, and which rule or word stops it.

Blocked messages

Messages the filter stopped in the last 7 days (Community chat and DMs), so you can spot new tricks and wrong blocks.

Ranks

Ranks show a colored prefix and icon in chat and above players' heads, and can let players use chosen commands without being operators. Changes reach the server within seconds. In game, operators can use /ranks.

Join screen

The GalaxySMP Main Menu: a full-screen title screen every time someone joins (and with /menu, the menu compass or Main Menu in /guide). A different 3D scene each time, the logo, a splash line, the player's character and the buttons Play, How to Play, Rules (from the rules below), What's New and Store. Play opens Featured Servers. Put **two stars** around words to make them bold.

Featured Servers

Add event "servers" here. Play means the main server (players carry on where they were; new players go to spawn). Other choices send players to spawn, a warp (make one in game with /setwarp) or the Minigame Center. "Coming soon" shows it but it can't be picked yet.
